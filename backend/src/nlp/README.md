Phase 3 implements an explainable French NLP pipeline using natural's French tokenizer and stemmer, deterministic intent rules, live RDF catalogue entity resolution, validated query plans and fixed SELECT templates. No LLM conversion APIs are used. `NlpService` orchestrates the modules and the existing read-only `SparqlClient` executes approved plans. See `docs/PHASE3.md` at the repository root for architecture, examples, limitations and isolated verification.
