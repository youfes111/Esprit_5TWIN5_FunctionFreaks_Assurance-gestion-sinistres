Phase 1 contains a closed registry of seven read-only SELECT templates and an injectable HTTP SPARQL client. Callers choose a registered query name; raw SPARQL and user-selected endpoints are not accepted. This registry implements no mutations, federation, or NLP. Fuseki setup is documented in `docs/FUSEKI_WINDOWS.md` at the repository root.

Phase 2 adds `claims.queries.ts` for validated, parameter-serialized claims SELECT/INSERT/DELETE-INSERT/DELETE operations, used only by ClaimsRepository. This does not open the Phase 1 registry to raw queries or writes. Controlled writes use a separate authenticated endpoint, default-disabled environment policy, Phase 4.5 session/RBAC authorization, metadata provenance and revision guards. See `docs/PHASE2.md` and `docs/ENABLE_CLAIMS_CRUD.md`.
